Proyecto destacado

BankConnect · accounts-service

Microservicio bancario con clientes, cuentas y movimientos de dinero: ingresos, retiros y transferencias. 12 endpoints REST sobre PostgreSQL, con su propia interfaz web y 32 tests. Lo hice para entender cómo se construye un backend de verdad, no solo un CRUD.

  • El dinero se maneja con BigDecimal, nunca con double. En Java 0.1 + 0.2 da 0.30000000000000004, y en un saldo bancario eso no vale.
  • Las transferencias son atómicas. Restar, sumar y registrar el movimiento pasan dentro de una transacción: o se hacen las tres cosas o no se hace ninguna.
  • Las cuentas se bloquean antes de tocar el saldo, y siempre en el mismo orden. Si no, dos transferencias cruzadas se quedan esperándose la una a la otra para siempre.
  • Ninguna cuenta se borra. Cambian de estado y sus movimientos se conservan, porque un banco no puede perder el histórico.
  • Los errores se traducen en un solo sitio al código HTTP que les toca, y ningún controlador tiene try/catch.
  • Arquitectura en capas: Controller → Service → Repository → Base de datos, y las entidades nunca salen al exterior.
